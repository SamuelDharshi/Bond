# bond-demo

Demo repository for **Bond**: refundable anti-spam deposits on Bitcoin Cash.

- Opening an issue here? Lock a small refundable chipnet deposit with the Bond web app.
- Label `valid` → the deposit is refunded. Label `slop` → it goes to charity. Nobody acts → anyone can return it after the timeout.

This repo runs on **chipnet (testnet)**. The maintainer key for this demo is **public and worthless**.
