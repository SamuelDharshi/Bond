## Confirmed rule: chipnet timelock

Chipnet runs Faster Blocks (~1-minute blocks, ~70 s measured) and keeps BIP68 block locks on the old 10-minute scale, so **1 lock unit = 10 blocks on chipnet** (mainnet = 1 for now). Sources and evidence are in `docs/DECISIONS.md`. The contract is unchanged; `relativeLockBlocksPerUnit` lives in `packages/core/src/network.ts`. Primary spec text for the exact formula and the mainnet date could not be read, so mainnet stays at factor 1 until it is checked.

## Remaining for the human

1. **Fund the contributor (≈2 min). Already done; ~900k sats left.**
   ```bash
   pnpm faucet          # opens the captcha image path; type the sum (gives ~1,017,000 sats)
   pnpm balance
   ```
2. **Run the real-chain suite (≈5–40 min; test 4 waits for one chipnet block).**
   ```bash
   pnpm e2e             # all txids → docs/proof/DEMO_TXIDS.md
   ```
3. **Create the GitHub repos.** Push this monorepo as a public repo named `bond`. Then:
   ```bash
   # in .env: BOND_DEMO_REPO=<you>/bond-demo  VITE_DEMO_REPO=<you>/bond-demo  BOND_ACTION_OWNER=<you>
   pnpm demo:repo       # uses gh if installed + `gh auth login`; otherwise prints exact manual steps
   pnpm demo:seed       # (a) bonded, (b) refunded, (c) forfeited, (d) reclaimable. Waits ~10 min until #4 is reclaimable.
   ```
   Optional Action e2e against the real GitHub API: `GITHUB_TOKEN=<pat with issues:write> BOND_E2E_REPO=<you>/bond-demo pnpm e2e`.
4. **Deploy the web app.**
   ```bash
   npx vercel --prod    # build env: BCH_NETWORK=chipnet, VITE_DEMO_MAINTAINER_WIF, VITE_DEMO_REPO, VITE_BLAZE_URL
   ```
   Or push to `main` and enable Pages (secret `VITE_DEMO_MAINTAINER_WIF`, variable `VITE_DEMO_REPO`). Then set `BOND_APP_URL` and `pnpm demo:config` so bot comments link to it.
5. **Scan with a real wallet.** Open the bond page, _Connect with WizardConnect_, and scan with a WizardConnect-capable wallet (e.g. Paytaca, Selene, or Cashonize, whichever supports WizardConnect + chipnet). Then lock and confirm a txid appears. This is the one integration step that couldn't be exercised here (no phone wallet).
6. **Mainnet flip** (follow `docs/MAINNET.md`): new keys, `BCH_NETWORK=mainnet`, fund ~0.002 BCH, `pnpm demo:seed`, redeploy, collect the 4 mainnet txids (fund, refund, forfeit, then `pnpm reclaim <issue #4 url>` for the reclaim).
7. **Submission chores**: paste `docs/submission/DECK.md` into the Widget Factory template (add QR + txids), record the video from `docs/submission/VIDEO_SCRIPT.md`, do the Telegram confirmation, set `VITE_BLAZE_URL`, and put your EMBER2026 / Community Choice `bitcoincash:z…` address in the README.
